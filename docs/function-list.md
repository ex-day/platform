# 機能一覧

画面・コンポーネントから呼び出される機能（F）の一覧。機能の定義は`docs/ui/functions/`に置く。IDの採番・廃止・参照のルールは[各種設計資料の作成方針](各種設計資料作成方針.md)の「画面・コンポーネント・機能のIDの採番ルール」（[DEC-0011](decisions/DEC-0011-id-numbering-rules.md)）に従う。IDは変えず、廃止したIDは再利用しない。

2026-11-15：根本整理（DEC-0019〜0023、[Issue #135](https://github.com/ex-day/platform/issues/135)）と [MVP スコープ v0.4](ex-day_mvp_scope.md) に合わせて作り直した。新しい機能（F05〜）の番号は候補であり、人が PR のレビューで確定する。既存の機能の定義ファイルは v0.3 の中身のままで、新しい機能の定義ファイルはまだない。

## 現行

| 機能ID | 機能名 | どこで使うか | MVP での中身・備考 |
|--------|--------|--------------|--------------------|
| F01    | [TOP の枠（discovery-sections）](ui/functions/F01-discovery-sections.md) | S01（TOP）の C11（TOP の枠の並び） | 旧名「Discovery Sections」。中身のある枠を決め、範囲を広げて探す（DEC-0022 決定2・3）。「いま、この時期」は Value の条件（Season 等）と今の一致、近さで並べる |
| F02    | [会話の解析（conversation-analysis）](ui/functions/F02-conversation-analysis.md) | 投稿のたびに裏で動く（バッチ。DEC-0018）。結果は S14 の C25（わかってきたこと）・C33（場所の候補）・C34（問い）に出す | Post から主張（Claim）を取り出し、わかってきたこと（Finding）・問い・場所の候補・Discovery の候補を作る（DEC-0015）。Discovery の候補を**自動で成立させる**のを基本にし、判断の記録に「方式＝自動」と規則・解析の版を残す（[MVP スコープ](ex-day_mvp_scope.md) 7節。条件は Issue #46）。タグの表記の揺れの吸収は MVP では外す |
| F05    | 投稿直後の地名の照合 | C27（新しい話を始める）の投稿の直後 | **新規（番号は候補）**。LLM を使わず、本文を地名の辞書と照合して場所の候補を出す。C31（場所の共有の誘い）を出すかの判定に使う（DEC-0023、Issue #82） |
| F06    | 寄り道の到達圏 | S12（寄り道）、C35（小さな地図）、S02 の上位の結果の移動時間 | **新規（番号は候補）**。起点・使える時間・終点から、寄れる場所と「そこで何分過ごせるか」、寄り道先のまとまりを出す。駅と表定速度で計算し、誤差は「行けない」側に寄せる（DEC-0013・0014）。駅・時間の刻みごとの事前計算を検討する |
| F07    | 探す（検索） | S02（探す）、C06（検索・絞り込み） | **新規（番号は候補）**。言葉・条件で場所・Discovery・企画を探す。「探しています」で絞ったときだけ、場所未定の会話・問いを返す。検索のための情報（SearchProfile）を使い、到達圏は全部の結果にはかけない |
| F08    | 場所の採用 | C33（場所の候補と採用）、C31（場所の共有の誘い）、入口から始めた会話 | **新規（番号は候補）**。場所の候補を採用・採用し直し・再検討中にする・取り消す。1つの判断の記録の中で行い、資料・会話・問いの採用した場所を食い違わせない（論理設計 6.2節）。新しい場所の案を採用したときは場所を作る |
| F09    | 番付の最初の並び | S16（企画の作成・編集）の C37（企画の並び） | **新規（番号は候補）**。場所の推定の値（坂の勾配等）の順を最初の並びとして出す。作った人が直せる（DEC-0021） |
| F10    | 通報と事後チェック | C39（通報）、S18（運営の管理） | **新規（番号は候補）**。通報の受付、暫定公開と事後チェックの一覧、非公開（DEC-0021 決定5、Issue #35） |

## MVP の対象外

ID と定義ファイルは残し、二次開発で使うかを決める。

| 機能ID | 機能名 | 理由 |
|--------|--------|------|
| F03    | [似たDiscoveryの案内（similar-discovery-guide）](ui/functions/F03-similar-discovery-guide.md) | 初期の MVP から外す（人の判断、2026-11-15）。投稿の直後は場所の共有の誘い（C31）を出すので、案内を重ねると負担が増える。器の前提（成立前の Discovery）もなくなった |
| F04    | [タグの補完（tag-suggest）](ui/functions/F04-tag-suggest.md) | タグ（DEC-0009 決定10）は MVP の対象外にした（人の判断、2026-11-15）。タグで表していたものは、会話から取り出す価値・Subject と重なる |

## 廃止済み

現時点でなし。
