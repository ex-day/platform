# 各種設計資料の作成方針について
## 概要
生成AIと各種設計を行う上でどのように作業を進めるか方針をここに決定する

## 対象AI
### 壁打ち・レビューAI
- ChatGPT
- Claude

### 実装AI
- Codex
- Claude code

### デザインAI
- Claude Design
- Figma AI

## 作成すべき資料
- 論理モデル
- Entity関連図
- ワイヤーフレーム
- 画面項目定義書
- API定義書

## 作成するにあたって必要な資料
- 画面定義書
- コンポーネント定義書
- MVPシナリオ

## 行いたいこと
### 論理モデル
1. MVPシナリオ、画面定義、コンポーネント定義を元に、粗めに要素を抽出
2. 抽出した要素を元にAIと壁打ちを実施し、MVPシナリオが通ることを確認
3. MVPシナリオに足りない要素がないか確認
4. AIと再度レビューを実施し、論理モデル設計書を出力し完了

### ワイヤーフレーム作成

1. issueをインプットとして作業指示をおこないワイヤーフレームを複数案作成する
2. Figmaに作成されたワイヤーフレームが登録される
3. 作成を指示した以外のAIでMVPが実現可能かレビューを行う
4. 作成されたワイヤーフレーム案のうち有力候補を1案に絞り込む
5. FigmaAIを用いて修正を行う 
6. 再度MVPが実現可能か、検討項目に漏れがないかレビューを行う
7. ワイヤーフレーム作成完了

### 画面項目定義書作成

1. 作成されたワイヤーフレーム、画面定義書、コンポーネント定義書を元に画面項目定義書作成を指示
2. yaml形式で画面項目定義書を作成
3. 作成された画面項目定義書を作成したAI以外でレビュー
4. 作成された画面項目定義書をhtml形式もしくはMarkdown形式で出力
5. html形式の画面項目定義書をもって最終確認
6. 画面項目定義書作成完了

### API定義書

1. 画面項目定義書および画面定義書、コンポーネント定義書をインプットとしてAIへ作業指示
2. OpenAPI形式でドキュメントを作成
3. 作成されたドキュメントを作成したAI以外でレビュー
4. レビューが完了したOpenAPI形式の定義書を最終確認
5. API定義書作成完了
