IDの採番・廃止・参照のルールは[各種設計資料の作成方針](各種設計資料作成方針.md)の「画面・コンポーネント・機能のIDの採番ルール」（[DEC-0011](decisions/DEC-0011-id-numbering-rules.md)）に従う。IDは変えず、廃止したIDは再利用しない。

2026-11-14：根本整理（DEC-0019〜0023、[Issue #135](https://github.com/ex-day/platform/issues/135)）と [MVP スコープ v0.4](ex-day_mvp_scope.md) に合わせて作り直した。場所・会話・企画・寄り道の画面を足し、Discovery を会話の器とする前提の S05・S06 を廃止した。新しい画面（S12〜S18）の ID は人が PR のレビューで確定する（DEC-0011 決定3）。各画面の定義ファイル（`docs/ui/screens/`）は、新しい画面はまだなく、既存の画面は v0.3 の中身のまま。画面の設計で作り直す。

### 運営の権限（共用の画面）

一般の画面（S03・S13・S14・S15）を、運営の権限でも使う。専用の詳細画面は足さない（PR #141 のレビュー）。

- 権限の判定はサーバー側で行う。画面は、返ってきた中身と操作を出すだけにする
- 非公開・統合済み・取り消された対象も、運営は S18 の一覧から詳細を開ける。一般のユーザーには見えない（直接の URL でも返さない）
- 詳細では、運営にだけ判断の記録（いつ・誰が・どの基準で・なぜ）を出す
- 戻すとき（非公開を戻す、統合や成立の取り消しを戻す）は、前の判断を書き換えず、新しい判断の記録を足す。MVP で戻す操作を画面に出すか、SQL で補うかは画面の設計で決める
- 将来の運営用 MCP に備えて、業務の処理・権限・監査を画面に依存させない

### 画面ではないもの

- **新しい話を始める**：画面ではなく、ヘッダーの「話す」や各ページの「話す」から開くモーダル[C27（新しい話を始める）](ui/components/C27-post-new.md)で行う。URL（`/posts/new`）を持ち、直接開ける（Issue #67）。入力は本文だけ（DEC-0023）。場所のページ・Discovery のページ・企画のページから開いたときは、入口を引き継ぐ
- **場所の共有の誘い**：投稿の直後に、C27 の中で出す（DEC-0023）。コンポーネントにする
- **場所を選ぶ部品**：地図で指す、現在地の近くから選ぶ、既存の場所を名前で探して選ぶ。場所の共有の誘い（C31）・会話の「場所を指して答える」（C33）・S16（企画の作成・編集）で共通にする。場所の共有の誘いでは名前で探すを出さず、文字を打たせない（DEC-0023）。コンポーネントにする（C32）

コンポーネントの ID は、画面の設計で採否を決めてから人が確定する（各種設計資料の作成方針「コンポーネントの新規追加（採番）」）。

### MVP の対象外の画面

- 資料のページ（二次開発の筆頭。[MVP スコープ](ex-day_mvp_scope.md) 14節）
- 対象（Subject）のページ（「この列車の話を全部見たい」。ドメイン設計 6.1節）
- 「探しています」の一覧のページ（S02 の絞り込みで見せる）
- 会話の一覧のページ（場所・企画・自分の話・探すからたどる）

## 出会う・探す・寄り道の役割分け

v0.3 の S01／S02 の責務境界（ex-day が提案するか、ユーザーに探索意思があるか）を引き継ぎ、寄り道を足して3つに分ける。対象のドメイン（場所・Discovery・企画）が広がっても、見せ方（提案・検索結果・地図）は変えない。

|観点|S01 TOP|S02 探す|S12 寄り道|
|----|----|----|----|
|答える問い|いま、ここで何がある？|この言葉・条件に合うものは？|ここから、この時間でどこに寄れる？|
|主体|ex-day が出す|ユーザーが探す|ユーザーが起点と時間を決める|
|探索意思|なくてよい|ある|ある（時間の制約がある）|
|起点と時間|推薦の材料（現在地、既定エリア）|任意（絞り込みの条件）|必須（起点、使える時間、終点）|
|見せ方|枠（中身のある枠だけ）|検索結果の一覧|全画面の地図と、寄れる場所の一覧|
|計算|SearchProfile と時期・近さ|SearchProfile（SQL・全文・ベクトル）|到達圏（駅と表定速度）|

- S02 は、到達圏を全部の結果にはかけない（性能を分散させるため。到達圏の計算は重く、言葉で探す用途の代わりにもならない）。上位の結果にだけ移動時間を添え、「ここから行ける範囲で絞る」で S12 に条件を渡す
- S01 の「もっと見る」、ヘッダーの検索の実行は S02 へ。S01 の小さな地図、ヘッダーの「寄り道」、S03・S13 の「ここから行ける」は S12 へ
- 結果のカード（場所・Discovery・企画）は、S01・S02・S12 で同じ部品を使う
