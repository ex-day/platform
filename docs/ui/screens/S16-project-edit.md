# S16 企画の作成・編集（project-edit）

> 2026-11-16 新規（[Issue #135](https://github.com/ex-day/platform/issues/135)）。画面 ID は画面一覧のとおり案（人がレビューで確定する）。本書で使う新しいコンポーネント（C28〜C40）・機能（F05〜F12）の番号も候補。

## 画面概要

企画を作る・直す画面。運営もユーザーも同じ画面で作る（[MVP スコープ](../../ex-day_mvp_scope.md) 8節。最初の数本は、この画面ができる前に運営がデータで入れてよい）。作った人だけが並びを直し、ほかの人の声（企画そのものの会話）を読んで反映する（[DEC-0021](../../decisions/DEC-0021-projects-by-operator-and-users.md) 決定4）。

## 画面パス

- 作成：`/projects/new`
- 編集：`/projects/[id]/edit`（作った人と運営だけ）

## 対象端末

- PC
- モバイル

## アクション

- 初期表示
  - 作成：空の入力で表示する。S17（企画の一覧）や TOP の「こんな番付、作ってみませんか？」から来たときは、型を選んだ状態で開いてよい
  - 編集：指定された企画を読み込む。作った人と運営以外は開けない（サーバー側で判定し、ほかの人には S15 を返す）
  - 未ログインでも入力を始められる（DEC-0010 決定2）
- 場所を足す（C32）
  - 選んだ場所を並びの最後に足す。同じ場所が並びにすでにあれば足さない
- 発見を足す
  - 名前で探して既存の Discovery を選び、並びの最後に足す
- 並べ替える・外す（C37）
  - ドラッグ、または上へ・下へで並べ替える。外すと並びからなくなる（場所や Discovery そのものは消えない）
- 推定の値で並べる（F09）
  - 推定の値の順に並べ直す。推定の値のない項目は最後に置く。そのあと作った人が手で直せる
- 公開する・保存する
  - 未ログインなら C08 でログインを求め、入力内容を引き継ぐ
  - 1人が作れる企画の数の上限を超えるときは、公開できないことを伝える（上限の値は要検討。MVP スコープ 18節）
  - F10（禁止語のチェック、暫定公開）を通す。公開した企画は暫定公開になり、事後チェックの対象になる
  - 並びを変えたら、並びの履歴のデータを残す（**要検討**：MVP でデータを残すか。MVP スコープ 18節。画面は作らない）
  - 保存したら S15 へ
- 取りやめる：確認のうえ、作成は元の画面へ、編集は S15 へ戻る

## 構成方針

- 上から「作る前のお知らせ」「型」「表題・呼びかけ・説明」「並び（場所を足す・発見を足す・推定の値で並べる）」「公開する」の順に置く。モバイルでも1画面の縦の流れで完結させ、別画面に分けない
- 型ごとに並びの見せ方を変える：コース・番付は番号を出して並べ替えられる、まとめ・記憶は番号を出さない
- 場所を足すは、場所の共有の誘いと同じ部品（C32）を使い、操作をそろえる
- 似た企画の案内、提案を取り込む専用の流れ、並びの履歴の画面は MVP では作らない（MVP スコープ 8節）

## 判断待ち・検討事項

- 作成のあとで型を変えられるか
- 企画の項目に、採用されていない新しい場所の案を足せるか（足せない案。足したいときは、まず会話で場所を採用してもらう）
- 発見を足すときの探し方（F07 を使う案）
- 下書きの保存（MVP では持たない案）
- 1人が作れる企画の数の上限の値、並びの履歴のデータを MVP で残すか
