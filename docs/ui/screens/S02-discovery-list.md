# S02 Discovery探索一覧
## 画面概要
ユーザーに明確な探索意思が生じた後、S01等の他画面から引き継いだ条件、またはC06等でユーザーが指定した条件に基づいてDiscoveryを一覧表示し、能動的な探索を支援する。
この責務はPC／モバイルで共通とする。検索フォームは共通ヘッダー（C01）内のC06に集約する。検索条件をユーザー自身が入力したかどうかではなく、明確な探索意思があるかどうかをS01との境界とする。
`/discoveries` を条件なしで直接開いた場合は、現在地（取得できない場合は既定エリア）と既定半径を既定条件として表示する。既定条件で0件の場合は探索範囲を広げ、範囲を拡大して表示していることをユーザーに示す。
## 対象端末
- PC
- モバイル

## アクション
- S01の「もっと見る」から遷移
  - S01で選択した提案テーマの条件を引き継いで一覧表示する
- S03の関係Discoveryの「さらに見る」から遷移
  - 該当する関係（派生元／派生したDiscovery／関連Discovery）の条件を引き継いで一覧表示する。専用一覧は設けない
- 共通ヘッダー（C01）内のC06で検索を実行
  - 指定した検索条件に基づいて一覧を更新する。他画面で実行した場合は条件を引き継いでS02へ遷移する
- 条件なしで直接アクセス
  - 現在地（取得できない場合は既定エリア）と既定半径で一覧表示する。0件の場合は探索範囲を広げ、拡大中であることを表示する。範囲を拡大しても0件の場合は、拡大中であることの表示を残したうえで、独立した0件メッセージは出さず、投稿促進CTA（C21）を一覧の代わりに表示する
- 投稿促進CTAを押下
  - S04 知識・疑問登録へ遷移する
- S03から戻る
  - 一覧のスクロール位置を復元する

## 検討事項
- 既定半径、探索範囲を拡大する刻み、現在地を取得できない場合の既定エリアは実装時に決定する。
- C21 Contribution CTAの出力条件（少数件の判定を含む）と文言は実装時に確定する。0件時の表示位置は案Bを有力とし、一覧上部の案Cは採用しない。C03 Discovery Cardは再利用しない。
- S03へ遷移後、時間を置いて戻った場合の順位・鮮度、再取得の基準、保持中に非公開となったDiscoveryの扱いは実装時に決定する。
- [S03 Discovery詳細](./S03-discovery-detail.md)の関係Discoveryの「さらに見る」は、探索意思が生じたものとしてS02の条件付き表示へ遷移する。関係の条件をS02へどう引き継ぎ、S02上でどう表示するか（条件チップ等）は未確定とする。
- 引き継いだ条件およびC06で指定した条件のS02上での表示方法、続きの取得方法（件数上限・ページング・追加読み込み）、取得失敗時の表示は未確定とする。
