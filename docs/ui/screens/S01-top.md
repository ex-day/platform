# S01 Discovery提案（サービスTOP）
## 画面概要
ex-dayがユーザーの位置・時間・興味などを推薦材料としてDiscoveryを提示し、
ユーザーが明確に探索を意識していなくても、意識していなかったDiscoveryとの出会いを作る。

## 対象端末
- PC
- モバイル

## 表示項目
| 論理名             | 物理名                                           | 種別      | 繰り返し | 親 | データ元 | データ項目 | 対象端末    | 備考 |
|--------------------|--------------------------------------------------|-----------|----------|----|----------|------------|-------------|------|
| 共通ヘッダー       | → [C01](../components/C01-header.md)             | component | -        | -  | -        | -          | PC/モバイル |      |
| Discovery Sections | → [C11](../components/C11-discovery-sections.md) | component | -        | -  | -        | -          | PC/モバイル |      |
| 共通フッター       | → [C02](../components/C02-footer.md)             | component | -        | -  | -        | -          | PC/モバイル |      |

## 関連機能
なし

## アクション
- C05の「もっと見る」を押下
  - 選択した提案テーマの条件を引き継いでS02 Discovery探索一覧へ遷移する
- 共通ヘッダー（C01）内のC06で検索を実行
  - 指定した検索条件を引き継いでS02 Discovery探索一覧へ遷移する
- S03から戻る
  - S01のタブ選択状態とスクロール位置を復元する

## 検討事項
- モバイルの一つのタブで継続閲覧できる範囲は未確定。無限スクロールも候補とし、最大件数、画面外カードの破棄（仮想化）によるメモリ・性能、およびC05「もっと見る」との役割分担をMockで確認する。
- S03へ遷移後、時間を置いて戻った場合の順位・鮮度、再取得の基準、保持中に非公開となったDiscoveryの扱いは実装時に決定する。
