# S07 signup
## 画面概要
認証プロバイダと連携し、ユーザー登録を行う。

## 対象端末
- PC
- モバイル

## 表示項目
| 論理名       | 物理名                               | 種別      | 繰り返し | 親 | データ元 | データ項目 | 対象端末    | 備考 |
|--------------|--------------------------------------|-----------|----------|----|----------|------------|-------------|------|
| 共通ヘッダー | → [C01](../components/C01-header.md) | component | -        | -  | -        | -          | PC/モバイル |      |
| 共通フッター | → [C02](../components/C02-footer.md) | component | -        | -  | -        | -          | PC/モバイル |      |

## アクション
- 外部認証プロバイダを選択
  - 外部認証プロバイダの認証を行う
  - 外部認証プロバイダの認証が成功した場合、ユーザー登録を行う
  - 呼び出し画面
    - C07（ドロップダウンメニュー）だった場合
      - S08 ユーザー編集画面へ遷移する
    - C27（新しい話を始める）で投稿を確定しようとした場合
      - C27（新しい話を始める）へ戻り、ログイン前の入力内容を引き継いで投稿を確定する（[DEC-0010](../../decisions/DEC-0010-duplicate-conversations-and-posting-auth.md) 決定2）
    - C26（みんなの声）で声を送ろうとした場合
      - 元のS03（Discovery詳細）へ戻り、ログイン前の入力内容を引き継いで送信する
## 検討事項
- 画面上の表示名はニックネームでよい（DEC-0010 決定2）。ニックネームの扱いの詳細（必須か、変更できるか等）はDEC-0010のDeferredに従い、S08（ユーザー情報更新）と合わせて検討する
- cognitoやauth0など認証サービスの決定を行う
- 認証サービス決定後必要な表示項目を決定する
