# S07 signup
## 画面概要
認証プロバイダと連携し、ユーザー登録を行う。

## 対象端末
- PC
- モバイル

## 表示項目
- C01: 共通ヘッダー
- C02: 共通フッター

## アクション
- 外部認証プロバイダを選択
  - 外部認証プロバイダの認証を行う
  - 外部認証プロバイダの認証が成功した場合、ユーザー登録を行う
  - 呼び出し画面
    - C06 ドロップダウンメニューだった場合
      - S08 ユーザー編集画面へ遷移する
    - S04 知識・疑問登録／編集画面
      - S05 知識・疑問詳細画面へ遷移する
## 検討事項
- cognitoやauth0など認証サービスの決定を行う
- 認証サービス決定後必要な表示項目を決定する
