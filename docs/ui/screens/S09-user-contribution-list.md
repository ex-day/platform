# S09 自分の話（my talks）

> 2026-11-16 根本整理（DEC-0019〜0023、[Issue #135](https://github.com/ex-day/platform/issues/135)）に合わせて書き直した。旧名「自分の投稿一覧」（`/account/contributions`）。v0.3 の定義（知識・疑問の履歴、確認が必要な項目の補完、Discovery へのつながり）は Git の履歴にある。本書で使う新しいコンポーネント（C28〜C41）・機能（F05〜F12）の番号は候補。

## 画面概要

自分が始めた会話・書いた返信・作った企画をまとめて見て、返信や答えが来たこと、自分の会話から分かってきたこと・生まれた発見を確かめる。場所が決まっていない自分の会話が誰かに届いているか、「あとで」にした場所の共有の誘いに後から答えられる場所でもある（[DEC-0023](../../decisions/DEC-0023-no-place-input-on-post.md)、ドメイン設計 3.4節）。

MVP では通知の配信（メール・プッシュ）を持たないので、返信や答えが来たことは、この画面で分かるようにする（[MVP スコープ](../../ex-day_mvp_scope.md) 6節）。

## 画面パス

- `/account/talks`（ログインが要る）
- 今の実装（`/account/contributions`）は v0.3 の形。パスの移行は実装の段で行う

## アクション

- 初期表示
  - 未ログインなら C08 でログインを求める
  - 自分が書いた Post を持つ会話と、自分が作った企画を出す。非公開の措置を受けた自分の Post・企画も、自分には出す（「運営により非公開」と理由の分類）
  - 新しい動きは、前にこの画面を見た時点より後の動きを出す（**案**：「前に見た時点」の持ち方は実装で決める。通知の配信は MVP では持たない）
- 会話カード を押下：S14 へ
- 答えていない場所の共有の誘いに答える（C31）：候補をワンタップで確かめる、または地図・近くから選ぶ。F08 を呼ぶ。「共有しない」を選ぶと、この一覧から外す
- 誘いから「会話で場所を選ぶ」を押下：S14 へ。C33 の場所を選ぶ操作を開いた状態で出す（S14）
- 発見のカード を押下：S03 へ。企画カード を押下：S15 へ。企画を作る を押下：S16 へ
- 絞り込みを切り替える：一覧を切り替える

## 構成方針

- 上から「新しい動き」「答えていない場所の共有の誘い」「自分の会話（と生まれた発見）」「自分の企画」の順に置く。中身のない区画は出さない
- 新しい動きは、自分が知りたいこと（返信が来た、答えが寄せられた、場所が決まった、発見になった）を短い文で出し、押すとその会話へ進める
- 場所が決まっていない会話には、どこに届いているか（候補の場所のページ、TOP の探しています）を添え、場所未定でも届いていることが分かるようにする（DEC-0023 決定4）
- 評価・成績（いいねの合計、ランキング）のようには見せない。リアクションの数は会話カードの中の小さな数字にとどめる
- v0.3 の「確認が必要な項目の補完」は、場所の共有の誘いと、会話の中の問い（S14）に置き換えた

## 判断待ち・検討事項

- 「前に見た時点」の持ち方と、新しい動きの件数・期間
- 絞り込みの種類（すべて／始めた会話／返信した会話／自分の企画の案）
- 最小限の通知を MVP に入れるか（MVP スコープ 18節）
- 退会したときのこの画面の扱い（退会時の扱いは二次開発。規約の定めは外部公開の前。MVP スコープ 12・14節）
