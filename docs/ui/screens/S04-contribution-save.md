# S04 contribution save
## 画面概要
知識・疑問の新規登録もしくは編集を行う。

## 対象端末
- PC
- モバイル

## 表示項目
- C01: 共通ヘッダー
- 投稿種別
  - 知識
  - 疑問
- 画像
- 場所
- 時間
- 季節
- 本文
- 保存ボタン
- C02: 共通フッター

## アクション
- 初期表示時
  - 知識・疑問を指定されていた場合、既存の知識・疑問を表示し編集モードとする
  - 知識・疑問を指定されていない場合、新規作成モードとする
- 保存ボタン押下
  - 入力内容を検証する 
    - 必須項目
    - 禁止ワード
    - 不適切画像
  - NG エラー表示
  - OK 認証状態を確認する
    - 認証済みの場合　知識・疑問を登録する
    - 未認証の場合　警告メッセージを表示
      - ログインするを選択した場合　ログインダイアログを表示しログイン後公開状態で保存
      - そのまま保存するを選択した場合　非公開状態で保存する
    - 保存成功 S05 知識・疑問詳細へ遷移する 

## 検討事項
-  未認証保存データの扱いについて検討を行う
