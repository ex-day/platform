# S04 contribution save
## 画面概要
知識・疑問の新規登録もしくは編集を行う。

## 対象端末
- PC
- モバイル

## 表示項目
| 論理名       | 物理名                               | 種別      | 繰り返し | 親 | データ元 | データ項目 | 対象端末    | 備考                                                   |
|--------------|--------------------------------------|-----------|----------|----|----------|------------|-------------|--------------------------------------------------------|
| 共通ヘッダー | → [C01](../components/C01-header.md) | component | -        | -  | -        | -          | PC/モバイル |                                                        |

## アクション
- 初期表示時
  - 未認証の場合も新規作成モードで入力を開始できる
  - 知識・疑問を指定されていた場合、既存の知識・疑問を表示し編集モードとする
  - 知識・疑問を指定されていない場合、新規作成モードとする
- 資料を追加
  - 「資料を追加（任意）」「写真・動画・PDFなど、この投稿に関連する資料を追加できます」と案内する
  - PCではファイル選択とドラッグ＆ドロップを利用できる構成とする
  - モバイルでは端末が提供するカメラ、写真・動画ライブラリ、ファイル選択等につなげられる構成とする
  - 複数の資料を追加・確認・削除できるようにする
- 保存ボタン押下
  - 入力内容を検証する 
    - 必須項目
    - 禁止ワード
    - 不適切資料
  - NG エラー表示
  - OK 入力内容と新規作成／編集の状態を引き継ぎ、[S11 知識・疑問登録確認画面](./S11-contribution-save-confirm.md)へ遷移する
  - S11で「入力内容を修正する」を押下して戻った場合は、入力内容を保持する

## 検討事項
- 投稿確定時に認証を必須とするか、および認証が必要な場合に入力内容を認証後へ引き継ぐ方法は、認証フローと合わせて検討する（Non-blocking）
- MVPで許可するMedia Type、ファイルサイズ、動画時間、Live Photos等の扱い、不適切資料の検出・モデレーション方式は[Issue #35](https://github.com/ex-day/platform/issues/35)で確定する。本画面では動画をドメイン／UI上の対象から除外せず、具体的な制限を確定しない
- `contribution_media`は既存ドメイン／論理Entity設計の仮定義Mediaとの対応を示すUI上の名称であり、Mediaの属性・関係やAPI／物理データ構造の最終形は本画面では確定しない
