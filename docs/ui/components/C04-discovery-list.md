# C04 discovery-list
## 機能概要
C03 discovery cardの集合を表示する。

## 対象端末
- PC
- モバイル

## 表示項目
| 論理名         | 物理名                           | 種別      | 繰り返し | 親 | データ元 | データ項目 | 対象端末    | 備考 |
|----------------|----------------------------------|-----------|----------|----|----------|------------|-------------|------|
| discovery card | → [C03](./C03-discovery-card.md) | component | 0..n     | -  | -        |            | PC/モバイル |      |

## アクション
- 初期表示
  - 指定された条件に該当するDiscoveryを一覧表示する

## 検討事項
- 呼び出し元および対象端末に応じたCardの表示方向・レイアウトはワイヤーフレーム/デザイン時に決定する。
