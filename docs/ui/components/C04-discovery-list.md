# C04 discovery-list
## 機能概要
C03 discovery cardの集合を表示する。

## 対象端末
- PC
- モバイル

## 表示項目
| 論理名         | 物理名                           | 種別      | 繰り返し | 親 | データ元 | データ項目 | 対象端末    | 備考 |
|----------------|----------------------------------|-----------|----------|----|----------|------------|-------------|------|
| discovery card | → [C03](./C03-discovery-card.md) | component | 0..n     | -  | -        |            | PC/モバイル |      |

## アクション
- 初期表示
  - 指定された条件に該当するDiscoveryを一覧表示する

## 検討事項
- S01・S02の一覧は同じ表示とする。PC: 4列グリッド・縦型カード、モバイル: 縦型1列（S02のWireframe・Mockの比較で確定）。3列・横型・2列コンパクトは採用しない。
- 上記以外の呼び出し元（S03の関係Discoveryのモバイル横スクロール等）のCardの表示方向・レイアウトは、各画面の定義とワイヤーフレーム/デザイン時に決定する。
