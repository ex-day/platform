# C16 contribution status
## 機能概要
投稿者本人が知識・疑問の現在の状態と、後から変更できる解釈・分類を確認する。内部状態名やAI解析の生ログ・信頼度をそのまま表示しない。

## 対象端末
- PC
- モバイル

## 表示項目
| 論理名 | 物理名 | 種別 | 繰り返し | 親 | データ元 | データ項目 | 対象端末 | 備考 |
|--------|--------|------|----------|----|----------|------------|----------|------|
| 現在の状態 | contribution_status | text | - | - | API | status | PC/モバイル | 「Discoveryはまだ決まっていません」「場所の確認が必要です」などユーザー向けに表現 |
| 対象場所・時期 | contribution_context | text | 0..n | - | API | confirmedContext | PC/モバイル | 現在確定した解釈のみ表示。未確定はその旨を示す |
| 内容分類 | contribution_subject | text | - | - | API | subject | PC/モバイル | 現在確定した分類。未確定はその旨を示す |
| 内容を編集する | - | button | - | - | - | - | PC/モバイル | 本人のみ |

## アクション
- 初期表示時
  - 現在の状態を、確認待ち・未確定・関連済み等の意味が伝わる文言で表示する。候補と確定情報を混同しない。
- 内容を編集する押下時
  - [S04 知識・疑問登録／編集](../screens/S04-contribution-save.md)へ編集モードで遷移する。

## 検討事項
- 状態文言の詳細は状態の確定方法と合わせて実装設計で決める。
