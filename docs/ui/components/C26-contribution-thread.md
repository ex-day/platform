# C26 contribution-thread（仮称）
## 機能概要
Discoveryに紐づくContribution（コメント）を時系列に表示し、その場で新しいコメントを投稿できるようにするコンポーネント。DEC-0005によりContributionは発言（コメント）としての参加に一本化され、S05・S06へ遷移せずS03上で完結する。

正式なコンポーネントIDはC26として仮に採番する。既存コンポーネントとの採番調整は後続で確認する。

## 対象端末
- PC
- モバイル

| 投稿日時 | contributed_at | text | - | コメント | API | created_at | PC/モバイル | 相対表現（n日前 等） |

## アクション
- 初期表示
  - Discoveryに紐づくコメントを時系列で取得する
  - コメント総数が表示上限n件以下の場合はすべて表示し、「過去のやりとりをすべて見る」は表示しない
  - n件を超える場合、直近n件を常時表示し、それ以前のコメントを折りたたむ
- 「過去のやりとりをすべて見る」押下
  - 折りたたまれていたコメントを展開表示する。件数が非常に多い場合のページング方式は検討事項とする
- コメント投稿
  - 入力欄にテキストを入力し送信すると、新しいコメントとして末尾に追加される
  - 投稿された本文はC25（discovery-emerging-terms）の語句抽出処理の入力となる
- 「資料・画像を追加する」押下
  - 資料・画像を選択すると、C23（出典登録ダイアログ）を経由せず、出典状態＝未設定のまま即座にコメントへ添付・公開する。添付先はDiscoveryとする（DEC-0005 Decision 8）
  - 出典を選択時に登録したい場合は、添付操作とは別にC23を任意に呼び出せるようにする
- 添付資料の出典表示（「出典：〇〇」「出典：未設定」）を押下
  - C23を表示し、出典状態・出典情報を登録または編集する。呼び出し元が投稿者本人か他の参加者かは問わない（検討事項参照）

## 検討事項
- 常時表示する直近件数n（Wireframeではn=2で試作。Issue #48の成果物を参照）
- 「過去のやりとりをすべて見る」展開後、件数が多い場合のページング方式（追加ロード／明示的ページ送り）
- 出典表示の具体的なフォーマット
- 【追加（Issue #48）】資料添付時に出典登録を必須にすると投稿障壁になるため、添付は即時公開・出典登録は任意かつ事後（あとから重要と分かった時点等）に行える設計とした。この方針の詳細（登録を促すタイミング、投稿者以外による登録・編集の可否）はC23の検討事項を参照
- 未ログイン時の投稿導線（C08ログイン認証ダイアログとの関係）
- S06（知識・疑問一覧）が本コンポーネントに統合されることに伴う、S06自体の廃止判断（DEC-0005 Consequences参照）
