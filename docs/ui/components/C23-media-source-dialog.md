# C23 media source dialog
## 機能概要
Contributionへ追加した資料ごとに、出典状態と出典情報を登録・編集するダイアログコンポーネント。

## 対象端末
- PC
- モバイル

## 表示項目
| 論理名                 | 物理名                   | 種別      | 繰り返し | 親 | データ元 | データ項目     | 対象端末    | 備考                                                                                         |
|------------------------|--------------------------|-----------|----------|----|----------|----------------|-------------|----------------------------------------------------------------------------------------------|
| 対象資料               | contribution_media       | file      | 1        | -  | API      | media          | PC/モバイル | プレビュー、ファイル名、種別を表示                                                         |
| 出典状態               | media_source_status      | select    | 1        | -  | API      | sourceStatus   | PC/モバイル | 未設定（初期値）／自分で撮影・作成／出典を登録／出典不明                                   |
| 出典の種類             | media_source_type        | select    | 0..1     | -  | API      | sourceType     | PC/モバイル | Webサイト／書籍・雑誌／文書・史料／他者から提供／その他。出典を登録する場合に表示           |
| 出典名                 | media_source_name        | text      | 0..1     | -  | API      | sourceName     | PC/モバイル | ページ名、書名、史料名、提供者等                                                           |
| 出典URL                | media_source_url         | url       | 0..1     | -  | API      | sourceUrl      | PC/モバイル | Webサイト等の参照先                                                                         |
| 出典補足               | media_source_note        | textarea  | 0..1     | -  | API      | sourceNote     | PC/モバイル | 著者・発行者、発行年、ページ、所蔵元、管理番号等を含む任意の補足                             |
| 撮影・作成日時         | media_created_at         | date/time | 0..1     | -  | API      | createdAt      | PC/モバイル | 任意。資料メタデータから取得した場合は候補として表示し、ユーザーが確認・変更できるようにする |
| 資料の対象年代・時期   | media_target_time        | text      | 0..1     | -  | API      | targetTime     | PC/モバイル | 任意。撮影・作成日時とは別に、資料が記録・記述している対象年代・時期                         |

| キャンセル             | -                        | button    | -        | -  | -        | -              | PC/モバイル | 変更を確定せずダイアログを閉じる                                                           |

## アクション
- 呼び出しのタイミング（DEC-0005・Issue #48を踏まえて明確化）
  - 資料添付時に本ダイアログを開くことを必須にしない。C26等から資料を添付した直後は出典状態＝未設定のまま即座に公開してよい
  - 未設定の資料は、添付元（C26のコメント等）の資料表示に「出典：未設定（登録する）」のようなリンク表示を残し、いつでも本ダイアログを呼び出せるようにする
  - 出典を登録済みの資料も、「出典：〇〇（編集する）」のように同じ表示から再度呼び出し、後から編集できるようにする
- 初期表示時
  - 呼び出し元から対象資料と、設定済みの場合は出典状態・出典情報を受け取って表示する。未設定の場合は出典状態＝未設定として表示する
  - 資料メタデータから撮影・作成日時を取得できる場合は候補として表示し、自動確定しない
- 自分で撮影・作成を選択
  - 出典状態を自分で撮影・作成とする
  - 必要に応じて撮影・作成日時と資料の対象年代・時期を入力できるようにする
- 「出典を登録」を選択
  - 出典の種類、出典名、出典URL、出典補足を入力できるようにする
  - 出典の種類に応じて不要な項目は省略できるようにする
- 出典不明を選択
  - 出典が分からないことを明示した状態として設定できるようにする
- 設定ボタン押下
  - 出典状態と入力した出典情報を対象資料へ設定し、呼び出し元へ返す
- キャンセル押下
  - 編集中の変更を破棄し、呼び出し元の資料一覧へ戻る

## 検討事項
- 出典の詳細情報は任意とし、出典情報がないことだけを理由にContribution投稿を拒否しない
- 【更新（DEC-0005・Issue #48）】S04／S11を前提とした「投稿確定前に出典状態の選択を促す」という導線は、ContributionがS03上のコメントとして即時成立するDEC-0005のモデルとは前提が合わなくなっている。出典登録を投稿の障壁にしないため、添付時点でのダイアログ表示・状態選択の強制は行わず、未設定のまま公開できることとする
- 出典登録・編集を促すタイミングは、投稿時点ではなく資料の重要度が明らかになった時点（一定のリアクション・コメントが集まった、その他の魅力やHeroの画像として採用された等）を主とする。具体的な検知条件・通知方法は画面設計時に検討する
- 出典の登録・編集を、資料を添付した本人以外（議論に参加した他のユーザー）が行えるようにするかどうかを検討する。他者が後から出典に気づくケース（Issue #48で確認）を想定する場合、編集権限の範囲を定義する必要がある
- 複数資料へ同じ出典を一括設定する機能と、すべて自分で撮影・作成として設定する機能は、利用状況を踏まえて画面設計時に検討する
- 外部URL自体を資料として追加するか、添付資料の出典URLとしてのみ扱うかはIssue #35および画面設計時に検討する
- 出典を登録しても資料を転載・投稿する権利または許諾があることを意味しない。権利・利用許諾の確認は出典登録と分け、具体的な確認方法は利用規約・権利設計と合わせて検討する
- 本Componentの入力と既存ドメインのSource／Evidenceとの対応、およびAPI／物理データ構造の最終形は本Componentでは確定しない
