# C18 contribution confirmation
## 機能概要
投稿者本人に確認が必要な内容を具体的に示し、知識・疑問の補完へ案内する。確認が必要な項目がある場合のみS05で表示する。

## 対象端末
- PC
- モバイル

## 表示項目
| 論理名 | 物理名 | 種別 | 繰り返し | 親 | データ元 | データ項目 | 対象端末 | 備考 |
|--------|--------|------|----------|----|----------|------------|----------|------|
| 確認が必要な内容 | confirmation_request | text | 1..n | - | API | confirmationRequests | PC/モバイル | 「場所を確認してください」「関連するDiscoveryを選んでください」「情報を補足してください」など |
| 確認・補完する | - | button | - | - | - | - | PC/モバイル | 確認対象を引き継ぐ |

## アクション
- 初期表示時
  - 本人に確認が必要な項目だけを表示する。未確定というだけで一律に確認を要求しない。
- 確認・補完する押下時
  - 対象の知識・疑問と確認事項を引き継ぎ、[S04 知識・疑問登録／編集](../screens/S04-contribution-save.md)へ編集モードで遷移する。S04から[S11 知識・疑問登録確認画面](../screens/S11-contribution-save-confirm.md)へ進み、場所・Discovery候補・追加情報を確認する。

## 検討事項
- 投稿後の確認でS04→S11を使う場合の入力保持と確認項目へのフォーカスを実装設計で決める。
