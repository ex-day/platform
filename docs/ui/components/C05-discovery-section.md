# C05 discovery-section
## 機能概要
指定されたグループ条件に基づくDiscoveryのまとまりを、タイトルとC04 Discovery Listで表示する。

## 対象端末
- PC

## 表示項目
- タイトル
- C04 discovery list
- 「もっと見る」

## アクション
- 初期表示
  - 指定されたグループ条件に対応する表示名をタイトルに設定する
  - グループ条件を C04 discovery list に渡す
- 「もっと見る」を押下
    - グループ条件を引き継いで S02 discovery list へ遷移する

## 検討事項
なし
