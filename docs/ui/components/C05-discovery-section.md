# C05 discovery-section
## 機能概要
指定されたグループ条件に基づくDiscoveryのまとまりを、タイトルとC04 Discovery Listで表示する。

## 対象端末
- PC

## 表示項目
| 論理名         | 物理名                           | 種別       | 繰り返し | 親 | データ元 | データ項目 | 対象端末    | 備考                                                          |
|----------------|----------------------------------|------------|----------|----|----------|------------|-------------|---------------------------------------------------------------|
| タイトル       | sectionTitle                     | text       | -        | -  | API      | title      | PC          | モバイルの場合表示しない                                      |
| discovery list | → [C04](./C04-discovery-list.md) | component  | -        | -  | -        |            | PC/モバイル |                                                               |
| 「もっと見る」 | more                             | label/link | -        | -  | -        |            | PC/モバイル | タブ毎に1件表示。タイトルは非表示（タブラベルと重複するため） |

## アクション
- 初期表示
  - PCの場合：指定されたグループ条件に対応する表示名をタイトルに設定する
  - グループ条件を C04 discovery list に渡す
- 「もっと見る」を押下
    - 選択した提案テーマをさらに探索する意思が生じたものとして、グループ条件を引き継いでS02 Discovery探索一覧へ遷移する

## 検討事項
- S01モバイルのタブ内で継続閲覧できる範囲は未確定。無限スクロール、最大件数、仮想化の実現性をMockで確認し、「もっと見る」からS02へ遷移する役割との境界を整理する。
- S03から戻った場合は、親画面の方針に従ってタブ選択状態とスクロール位置を復元する。時間経過後の順位・鮮度や非公開となったDiscoveryの扱いは実装時に決定する。
