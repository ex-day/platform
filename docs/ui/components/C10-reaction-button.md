# C10 reaction button

## 機能概要
Discoveryまたは知識・疑問に対して、ユーザーがリアクションを行うためのボタンを表示する。

## 対象端末
- PC
- モバイル

## 表示項目
| 論理名             | 物理名 | 種別   | 繰り返し | 親 | データ元 | データ項目 | 対象端末    | 備考 |
|--------------------|--------|--------|----------|----|----------|------------|-------------|------|
| リアクションボタン | -      | button | -        | -  | -        | -          | PC/モバイル |      |
| リアクション数     | -      | text   | -        | -  | -        | -          | PC/モバイル |      |

## アクション
### リアクションボタン押下
- ログイン済みの場合、対象へのリアクション状態を更新する
- 未ログインの場合、C08 ログイン認証ダイアログを表示する

## 検討事項
- リアクションの種類および表現方法はデザイン時に検討する
- 同一ユーザーによるリアクションの付与・解除方法はデザイン時に検討する
