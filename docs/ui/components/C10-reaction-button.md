# C10 reaction button

## 機能概要
ユーザーがリアクションを行うためのボタンを表示する。リアクションの対象は、Post（声）、Discovery、わかってきたこと（価値・説）、Valueとする（[DEC-0009](../../decisions/DEC-0009-conversation-understanding-and-tags.md) 決定9）。対象ごとにリアクションの意味と種類が異なる。

| 対象 | リアクションの意味 | 使う場所 | 注意 |
|---|---|---|---|
| Post（声） | 発言への共感。問いを投げた声への「自分も気になる」 | C26（みんなの声） | ― |
| Discovery | Discoveryへの関心・共感 | S03（Discovery詳細） | ― |
| 価値（わかってきたこと・採用後のValue） | 「わかる」「行ってみたい」 | C25（わかってきたこと）、C12（Discovery Value）等 | 確からしさ・推薦の材料 |
| 説（裏付けのないもの） | 「そうかも」 | C25（わかってきたこと） | 正しさの証拠にはしない。票の多い説を正解のように見せない |
| 説（裏付けのある知識）、Subject・Condition単独 | 付けない | ― | 確からしさは資料・出典で決まる。Subject・Condition単独へのリアクションは意味をなさない |

## 対象端末
- PC
- モバイル

## 表示項目
| 論理名             | 物理名 | 種別   | 繰り返し | 親 | データ元 | データ項目 | 対象端末    | 備考 |
|--------------------|--------|--------|----------|----|----------|------------|-------------|------|
| リアクションボタン | -      | button | -        | -  | -        | -          | PC/モバイル | 種類は対象ごとに上表のとおり |
| リアクション数     | -      | text   | -        | -  | -        | -          | PC/モバイル | 説へのリアクション数を、正しさの指標のように強調しない |

## アクション
### リアクションボタン押下
- ログイン済みの場合、対象へのリアクション状態を更新する。わかってきたことへのリアクションは、その時点の版に対して記録する（DEC-0009 決定4）
- 未ログインの場合、C08 ログイン認証ダイアログを表示する

## 検討事項
- リアクションの種類および表現方法はデザイン時に検討する
- 同一ユーザーによるリアクションの付与・解除方法はデザイン時に検討する
- 声（Post）へのリアクションの種類（Discoveryと同じ👍／😮／♥とするか、共感・「自分も気になる」に絞るか）はWireframe・モックで確認する

## S03での利用方針
- [S03 Discovery詳細](../screens/S03-discovery-detail.md)のDiscoveryへのリアクションでは、👍／😮／♥の3種類を併記し、同一ユーザーが複数の種類を付与できる構成とする。
- S03のC25（わかってきたこと）では、価値に「わかる」「行ってみたい」、裏付けのない説に「そうかも」を表示する。
- S03以外の画面で同じ種類・表現・複数付与を採用するかは、各画面の設計で決定する。
