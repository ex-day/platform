# C11 discovery sections
## 機能概要
グループ条件を取得し、モバイルの場合タブ形式としタブの内容にlistを表示、PCの場合は1件以上のsectionを表示する。

## 対象端末
- PC
- モバイル 

## 表示項目
| 論理名         | 物理名                              | 種別      | 繰り返し | 親             | データ元 | 対象端末 | 備考                                                          |
|----------------|-------------------------------------|-----------|----------|----------------|----------|----------|---------------------------------------------------------------|
| section        | → [C05](./C05-discovery-section.md) | component | 1..n     | -              | -        | PC       |                                                               |
| セクションタブ | section_tab                         | component | 1..n     | -              | -        | モバイル | セクション表示名をタブラベルとして使用                        |
| discovery list | → [C05](./C05-discovery-section.md) | component | 1        | セクションタブ | -        | モバイル | タブ毎に1件表示。タイトルは非表示（タブラベルと重複するため） |

## 関連機能
- F01: discovery section

## アクション
- 初期表示
  - F01を実行し表示対象を取得する
  - 対象端末に応じsectionもしくはセクションタブを表示する
- S03から戻る
  - モバイルでは選択していたセクションタブとタブ内のスクロール位置を復元する

## 検討事項
- モバイルの一つのタブで縦方向に継続閲覧できる範囲は未確定。無限スクロール、最大件数、画面外カードの破棄（仮想化）によるメモリ・性能をMockで確認する。
- C05「もっと見る」でS02へ遷移する役割との境界、およびS03から時間を置いて戻った場合の順位・鮮度、再取得の基準、非公開となったDiscoveryの扱いは実装時に決定する。
