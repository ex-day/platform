# C22 location input
## 機能概要
Contribution等の対象場所を、地点またはエリアとして入力するダイアログコンポーネント。

## 対象端末
- PC
- モバイル

## 表示項目

## アクション
- 初期表示時
  - 呼び出し元から場所が渡された場合、その場所を初期入力として表示する
  - 初期入力は固定せず、ユーザーが確認・変更・解除・未指定化できるようにする
- 現在地を選択
  - 端末の位置情報の利用許可を求め、取得した位置を地図上に表示する
  - 位置情報を取得できない場合、地図または検索による入力へ切り替えられるようにする
- 地図から選択
  - 地点の場合は地図上にピンを指定する
  - エリアの場合は中心地点と周辺範囲を指定する
- 住所・施設名・駅名等から検索
  - 検索結果から地点または名前付き地域を選択し、地図上に表示する
- 場所の種類をエリアに変更
  - 中心地点からの周辺範囲、または名前付き地域を選択できるようにする
- 場所を設定ボタン押下
  - 地点またはエリアの入力内容を呼び出し元へ返す
- 未指定にするボタン押下
  - 設定済みの場所を解除し、未指定として呼び出し元へ返す

## 検討事項
- MVPでは自由な多角形の描画を必須とせず、エリアは中心地点と周辺範囲、または市区町村・町名等の名前付き地域で表現する
- 周辺範囲の選択肢、既定値、上限と、距離の入力単位は画面設計時に検討する
- 現在地は入力手段であり、Contributionが対象とする場所と自動的に同一とはみなさない。ユーザーが設定内容を確認して確定する
- Map API、住所検索、逆ジオコーディング、名前付き地域の境界データは実装設計時に決定する
- `place`の属性・API／物理データ構造、および地点・エリアと既存ドメイン／論理Entityとの最終的な対応は本Componentでは確定しない
