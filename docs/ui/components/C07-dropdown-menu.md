# C07 dropdown menu
## 機能概要
指定されたグループ条件に基づくDiscoveryのまとまりを、タイトルとC04 Discovery Listで表示する。

## 対象端末
- PC
- モバイル

## 表示項目
| 論理名           | 物理名 | 種別       | 繰り返し | 親 | データ元 | データ項目 | 対象端末    | 備考 |
|------------------|--------|------------|----------|----|----------|------------|-------------|------|
| メニューicon     | -      | image/link | -        | -  | -        | -          | PC/モバイル |      |
| ユーザー名       | -      | text       | -        | -  | -        | -          | PC/モバイル |      |
| 自分の投稿一覧   | -      | text/link  | -        | -  | -        | -          | PC/モバイル |      |
| ユーザー情報更新 | -      | text/link  | -        | -  | -        | -          | PC/モバイル |      |
| ログイン         | -      | text/link  | -        | -  | -        | -          | PC/モバイル |      |
| 新規ユーザー登録 | -      | text/link  | -        | -  | -        | -          | PC/モバイル |      |
| 新規知識登録     | -      | text/link  | -        | -  | -        | -          | PC/モバイル |      |
| about            | -      | text/link  | -        | -  | -        | -          | PC/モバイル |      |
| support          | -      | text/link  | -        | -  | -        | -          | PC/モバイル |      |
| ログアウト       | -      | label/link | -        | -  | -        | -          | PC/モバイル |      |

## アクション
- 初期表示
    - メニューiconを表示する
- メニューiconを押下
    - メニューicon以外の表示項目を表示する
      - ユーザー認証済みの場合
        - ユーザー名を表示
        - 自分の投稿一覧を表示
        - ユーザー情報更新を表示
        - ログアウトを表示
      - ユーザー認証未済の場合　ログイン/新規ユーザー登録を表示
- 自分の投稿一覧を押下
  - S09 自分の投稿一覧へ遷移
- ユーザー情報更新を押下
  - S08 ユーザー情報更新へ遷移 
- ログインを押下
  - C08 ログイン認証ダイアログを表示
- 新規知識登録を押下
  - S04 知識・疑問登録画面へ遷移
- 新規ユーザー登録を押下
  - S07 新規ユーザー登録画面へ遷移
- ログアウトを押下
  - ログアウト処理を実施

## 検討事項
なし
