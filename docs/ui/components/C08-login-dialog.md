# C08 login dialog

## 機能概要
ログインが必要な操作を行う際に、ユーザー認証を行うためのダイアログを表示する。

## 対象端末
- PC
- モバイル

## 表示項目
| 論理名                   | 物理名 | 種別       | 繰り返し | 親 | データ元 | データ項目 | 対象端末    | 備考 |
|--------------------------|--------|------------|----------|----|----------|------------|-------------|------|
| 認証プロバイダ選択       | -      | -          | -        | -  | -        | -          | PC/モバイル |      |
| 新規ユーザー登録への導線 | -      | label/link | -        | -  | -        | -          | PC/モバイル |      |
| 閉じる                   | -      | label/link | -        | -  | -        | -          | PC/モバイル |      |

## アクション
### 認証プロバイダを選択
- 選択した認証プロバイダによる認証を開始する
- 認証成功後、呼び出し元の操作を継続する

### 新規ユーザー登録を選択
- S07 新規ユーザー登録画面へ遷移する

### 閉じる
- ダイアログを閉じ、呼び出し元へ戻る

## 検討事項
- 利用する認証サービスおよび認証プロバイダは別途検討する
- 認証後の遷移・処理は呼び出し元の機能に従う
