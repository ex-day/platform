# C21 contribution CTA
## 機能概要
Discoveryの探索結果等を契機として、ユーザーへ知識・疑問などのContribution投稿を促し、S04へ案内するコンポーネント。

C03 Discovery Cardが既存Discoveryの提示とS03 Discovery詳細への導線を担うのに対し、C21はContribution投稿を促すCTAを担う。責務が異なるためC03を再利用しない。

## 対象端末
- PC
- モバイル

## 表示単位・制約
- C21は特定のカード形状に責務を限定しない。具体的な表示形態、配置、強調度は利用する画面とWireframeで検討する。
- S02での表示方針は次のとおりとする。
  - 0件（探索範囲を拡大しても該当なし）: 一覧の代わりに表示する（案B）。C21自身がEmpty Stateの説明とContributionへの誘導を兼ねるため、独立した「Discoveryが見つかりませんでした」等の0件メッセージは表示しない。探索範囲を拡大して表示した場合は、拡大しても0件のときも範囲拡大通知を残し、C21とは別に表示する。範囲拡大通知、独立した0件メッセージ、C21が同じ状態を重複して説明することを避けるための整理である。表示位置は案Bを有力とするが、実装時に確定する。
  - 少数件: 一覧の最後のCardとして出力する。Discoveryが実際に存在するため、「見つかりません」のような0件前提の文言は使わない。まだ発見の余地があることを伝え、知識・疑問の投稿を促す方向とする。
  - 通常件数: 原則表示しない。
  - 一覧上部に表示する案C（バナー）は採用しない。
- メッセージ文言は0件時と少数件時で出し分ける。0件時はDiscoveryが存在しないことを伝えて投稿を促し、少数件時はDiscoveryが存在することと矛盾しない表現で投稿を促す。文言の出し分けパターンは本コンポーネントの定義に含め、最終文言は未確定とする（Wireframe・Mock上の文言は仮置き）。
- C21を出力する条件（少数件の判定を含む）と出力する文言は、実装時に確定する。
- S01で利用するかは未確定とする。S02の比較案を他画面へ一律に適用しない。
- C21をDiscoveryとして扱わず、C03 Discovery Cardの集合や件数へ含めない。

## アクション
- 初期表示時
  - 利用コンテキストに応じたContribution投稿の案内と投稿導線を表示する。表示条件と表示場所は利用する画面側で定める。
- Contribution投稿導線押下時
  - [S04 知識・疑問登録／編集](../screens/S04-contribution-save.md)へ新規作成モードで遷移する。

## 検討事項
- 「少数件」と判定する具体的な件数・条件、およびPC／モバイル、一覧レイアウト、検索範囲によって判定条件を変える必要があるかを実装時に検討する。
- 0件時の表示位置（案B有力）を実装時に確定する。
- 0件時・少数件時の最終文言を実装時に確定する。
- S01を含むS02以外の画面で利用するかを検討する。
- CTAの具体的な表示形態と投稿導線の最終ラベルはデザインで決定する。Wireframe・Mock上の文言は仮置きとする。
- 探索条件等をS04へ引き継ぐか、引き継ぐ場合の項目と入力への反映方法は未確定とする。
