# C21 contribution CTA
## 機能概要
Discoveryの探索結果等を契機として、ユーザーへ知識・疑問などのContribution投稿を促し、S04へ案内するコンポーネント。

C03 Discovery Cardが既存Discoveryの提示とS03 Discovery詳細への導線を担うのに対し、C21はContribution投稿を促すCTAを担う。責務が異なるためC03を再利用しない。

## 対象端末
- PC
- モバイル

## 表示項目
| 論理名 | 物理名 | 種別 | 繰り返し | 親 | データ元 | データ項目 | 対象端末 | 備考 |
|--------|--------|------|----------|----|----------|------------|----------|------|
| Contribution投稿を促すメッセージ | contribution_cta_message | text | - | - | 未確定 | 未確定 | PC/モバイル | 探索結果等の利用コンテキストに応じて、知識・疑問などの投稿を促す。具体的な文言は未確定 |
| Contribution投稿導線 | - | button/link | - | - | - | - | PC/モバイル | ボタン、リンク等の具体的な表示形式と文言は未確定 |

## 表示単位・制約
- C21は特定のカード形状に責務を限定しない。具体的な表示形態、配置、強調度は利用する画面とWireframeで検討する。
- S02では一覧末尾、0件時の一覧代替、一覧上部を比較中とし、0件の場合のみ表示するか、少数件の場合にも表示するかは未確定とする。
- S01で利用するかは未確定とする。S02の比較案を他画面へ一律に適用しない。
- C21をDiscoveryとして扱わず、C03 Discovery Cardの集合や件数へ含めない。

## アクション
- 初期表示時
  - 利用コンテキストに応じたContribution投稿の案内と投稿導線を表示する。表示条件と表示場所は利用する画面側で定める。
- Contribution投稿導線押下時
  - [S04 知識・疑問登録／編集](../screens/S04-contribution-save.md)へ新規作成モードで遷移する。

## 検討事項
- S02における表示場所は、一覧末尾、0件時の一覧代替、一覧上部の比較案をWireframeで検証して決定する。
- 0件の場合のみ表示するか、少数件の場合にも表示するかを検討する。
- S01を含むS02以外の画面で利用するかを検討する。
- CTAの具体的な表示形態、文言、投稿導線のラベルはWireframeおよびデザインで決定する。Wireframe上の文言は仮置きとする。
- 探索条件等をS04へ引き継ぐか、引き継ぐ場合の項目と入力への反映方法は未確定とする。
